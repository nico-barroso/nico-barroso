Fully local RAG document assistant, grown out of my time at Phiteca-IA. LlamaIndex, ChromaDB and Ollama underneath, a custom Streamlit UI on top, multi-arch Docker images published to GHCR.
`Python` `LlamaIndex` `ChromaDB` `Ollama` `Docker`

An accessible menu assistant for small restaurants — hybrid RAG for allergen filtering, an MCP server exposing menu and analytics as tools, multi-tenant from the schema up, WCAG 2.1 AA because accessibility shouldn't be a "v2" feature. Also doubling as my Full Stack Master's final project.
