## 🚀 Featured projects

### 🐿 [Acorn](https://github.com/nico-barroso/acorn) · Final degree project 
A content-saving app with automatic Smart Folders. React Native + Next.js, Supabase as the backend.  
`React Native` `Next.js 15` `Supabase` `Expo`

### 🧠 [Kalima](https://github.com/nico-barroso/kalima) · Local RAG
A fully local RAG document assistant built with LlamaIndex, ChromaDB and Ollama. Custom Streamlit UI with animated chat. Multi-arch Docker images published to GHCR.  
`Python` `LlamaIndex` `ChromaDB` `Ollama` `Docker`

### ⚡ [fastask](https://github.com/nico-barroso/fastask) · v1.0.0 · Released
REST API for task management with full CRUD, pagination, soft delete and a `lists` resource. Containerized and published to GitHub Container Registry.  
`FastAPI` `Docker` `GHCR`
